# 网络控制器CTR 安装程序 — 使用说明

这是主控端的图形化安装包，把「选安装路径」「填教师机 IP」「设退出/解锁密码」这几步合并到一个安装向导里，装完之后：

- 教师机上有一个可以直接用的**主控端**（含数据库，已经按你填的信息配好网段和密码）；
- 同一个安装目录下的**被控端（学生机）**文件夹里只有一个已经配好的 `网络控制器学生端.exe`，**复制这一个文件到学生机双击**即可部署，不需要再手动改配置文件。

不需要单独去下载 `主控端（教师机）` 和 `被控端（学生机）` 两个文件夹再手动改配置 —— 这个安装包把那一步自动化了。

---

## 一、使用步骤

1. 双击 `网络控制器CTR安装程序.exe`。
2. **选择安装目录**（默认 `D:\NetControl`；电脑没有 D 盘时默认 `C:\Users\Public\Documents\NetControl`，都可以改）。
3. **选择教师机 IP**：安装程序会自动检测本机网卡列表，选连接学生机所在局域网的那一个；如果没检测到，会退化成手动填 IP + 子网掩码。下方会实时显示自动算出的局域网网段（写入被控端白名单放行范围用）。
4. **设置退出/解锁密码**：这一个密码会同时用作被控端托盘图标「退出」密码和拔网线锁屏「解锁」密码，输入两次确认一致。
5. 完成安装。安装目录下会看到：

   ```
   {安装目录}\
     主控端\
       网络控制器主控端.exe
       apply_config.exe        安装时用一次生成配置，留在原地，后续也可再用来重新生成配置
       controller.db           已经按你填的信息写好网段和密码
     被控端（学生机）\
       网络控制器学生端.exe     单文件安装器：已内置 CTR.exe、卸载脚本和本机配置（controller_url / 网段 / 密码哈希）
   ```

6. 把 **`网络控制器学生端.exe`**（或整个 `被控端（学生机）` 文件夹）复制到每台学生机的任意位置，比如桌面或 U 盘，双击运行。系统会弹一次 UAC 确认框（点"是"），不需要手动右键选"以管理员身份运行"。安装器会：
   - 把被控端解压到固定目录 **`C:\Users\Public\Documents\NetControl`**：
     ```
     C:\Users\Public\Documents\NetControl\
       CTR.exe               被控端服务程序
       config.json           被控端配置
       uninstall_agent.bat   卸载脚本（右键以管理员身份运行）
       install_agent.log     安装日志
     ```
   - 停止并卸载旧服务（升级时，包括以前从桌面文件夹装的旧版），再从上面的目录注册并启动服务；
   - 装完显示安装日志和结果。之后这个安装器和复制过去的文件夹**可以直接删掉**，服务从固定目录运行，不受影响。

   > 学生机装了还原卡时，要在还原卡的保护模式之外安装，否则重启后会被还原掉。

---

## 二、和手动部署的关系

`网络控制器学生端.exe` 也兼容旧的手动部署方式：exe 里没有内置配置时，会读取同一文件夹下的 `config.json`。

如果你更喜欢手动控制每一步，`主控端（教师机）/` 和 `被控端（学生机）/` 两个文件夹依然是独立可用的，可以完全不用这个安装包，参照各自的 `使用说明.md` 手动部署（手动改 `config.json` 里的 IP、手动去主控端「设置」页改密码）。这个安装包只是把这几步自动化，不是必须的。

---

## 三、源码

`源码/` 目录下是配置生成器（`apply_config.exe`）、被控端一键安装器（`agent_installer.py` → `网络控制器学生端.exe`，配置追加格式见 `payload.py`）的源码，以及 Inno Setup 安装向导脚本（`setup.iss`）。因为配置生成器要复用主控端的 `Database` 类来写 `controller.db`，所以带了一份 `controller/db/` 的精简拷贝（不是完整的主控端源码）。

如果只是想重新编译配置生成器 / 一键安装器本身：

```bat
pip install pyinstaller
pyinstaller 源码\installer\apply_config.spec --clean --noconfirm
pyinstaller 源码\installer\agent_installer.spec --clean --noconfirm
```

（一键安装器会内置 `dist\CTR.exe`，需要先打包被控端 `agent.spec`。）

如果想重新生成完整的安装包（主控端 + 被控端 + 配置生成器 + Inno Setup 打包），需要在完整的开发仓库（`主控端（教师机）/源码` 和 `被控端（学生机）/源码` 都在同一棵源码树下）里运行 `build_installer.bat`，并安装好 [Inno Setup](https://jrsoftware.org/isdl.php)（编译 `.iss` 用）——这里的 `源码/` 主要供理解配置生成器的实现，不是一个可以独立跑通整条打包流程的完整源码树。

单元测试（覆盖网段计算、密码哈希、配置文件写入等纯逻辑）：

```bat
pip install pytest
pytest 源码\tests\test_apply_config.py
```
